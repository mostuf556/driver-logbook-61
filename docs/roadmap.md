# Roadmap

- Cloud sync support for data persistence across devices
- Multi-site / multi-guard tenant isolation
- Offline-first PWA experience with IndexedDB
- Bulk operations for entries and exports
- Reporting dashboard for peak hours and dwell time
- Shift management and guard scheduling
- Better plate recognition with camera preview and confidence scoring
- QR / barcode scanning for driver badges
- Audit logs, push notifications, and PDF export
- LDAP / Active Directory integration
- Two-way SMS alerts via Twilio or similar
