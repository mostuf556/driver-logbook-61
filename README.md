# דוח נהגים — Driver Gate Report

A Hebrew-first RTL web app for managing driver entry/exit records at a gated facility. The app runs entirely in the browser and stores data in localStorage — no backend required.

See the detailed documentation in the `docs/` folder:

- [Overview](docs/overview.md)
- [Research](docs/research.md)
- [Roadmap](docs/roadmap.md)

Run locally:

```bash
npm install
npm run dev
```

Bugs, feature requests, and issues: https://github.com/mostuf556/driver-logbook-61/issues
